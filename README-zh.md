# Open Via IDE Context Menu Manager

Windows 工具，用于查看、备份、删除和添加「通过 IDE 打开」级联右键菜单项。

## 项目说明

支持文件、文件夹和目录背景上下文，删除前导出 .reg 备份；HKLM 修改需要管理员权限。测试：python -m unittest discover -s tests -v。

## 快速开始

```bash
git clone https://github.com/user1745/open-via-ide-context-menu-item-management.git
cd open-via-ide-context-menu-item-management
```
