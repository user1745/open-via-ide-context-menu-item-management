# Open Via IDE Context Menu Manager

A Windows tool to inspect, back up, remove and add entries in the Open via IDE cascading context menu.

## Project notes

Manages file, folder and directory-background contexts and exports .reg backups before changes. HKLM changes require elevation. Test with python -m unittest discover -s tests -v.

## Quick start

```bash
git clone https://github.com/user1745/open-via-ide-context-menu-item-management.git
cd open-via-ide-context-menu-item-management
```
